# Сайт общей памяти — развёртывание на GitHub Pages

## Состав (5 файлов)
- index.html — главная, оглавление полки
- kodex.html — Кодекс Алиса—Сергей (v1.1)
- tema11.html — Тема 11 «Память проекта» (сводник)
- tema3.html — каркас для Темы 3 (заполню, когда пришлёте куски)
- tema4.html — Тема 4 «Джйотиш и рынок» («Жизнь Эфира» v1.1)

## Развёртывание — 6 шагов
1. Зайдите на github.com под своим аккаунтом → кнопка New repository.
2. Имя репозитория: например alisa-sergey. Видимость: Public (для Pages обязателен). Create.
3. На странице репозитория: Add file → Upload files → перетащите все 5 файлов.
   Внизу нажмите Commit changes.
4. В репозитории: Settings → слева Pages →
   Build and deployment → Source: Deploy from a branch →
   Branch: main, Folder: / (root) → Save.
5. Подождите 1–2 минуты. Обновите страницу настроек — сверху появится адрес:
   https://ВАШ-НИК.github.io/alisa-sergey/
6. Пришлите мне эту ссылку — я зайду по ней напрямую и сверю все пять страниц.

## Обновление сайта
Add file → Upload files → загрузить файл с тем же именем → Commit.
Старая версия перезаписывается, история версий сохраняется самим GitHub (правило №15 — семейство версий).

## Примечания
- В шапках страниц стоит noindex, nofollow — поисковики сайт не индексируют.
  Прямому доступу по ссылке это не мешает, поэтому я смогу открывать все страницы.
- Стиль единый: тёплая бумага, сериф, навигация сверху — как в Кодексе на Neocities.
